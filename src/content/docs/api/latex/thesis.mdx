表紙の年度・学位種別を設定するためのコマンド

## 構文

```latex
\thesis{年度と学位種別}
```

## パラメータ

```latex
\thesis{
    body
}
```

- **body**

    表紙に出力する年度と学位種別を指定します

## 説明

`\makecover` が表紙上部に出力する文字列を設定します．
`\usepackage{settings}` の後，`\makecover` より前に一度指定してください．
卒論・修論の種別もここで決まります．

```latex
\thesis{２０２５年度卒業論文}
% \thesis{２０２５年度修士論文}
```

:::caution
テンプレートは値を検証・変換しません．
提出要件に従い，年度を全角数字で記述してください．
:::
