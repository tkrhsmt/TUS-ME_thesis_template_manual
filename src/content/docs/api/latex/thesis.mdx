---
title: thesis
description: 表紙の年度・学位種別を設定する
---

## 構文

```latex
\thesis{年度と学位種別}
```

## 説明

`\makecover` が表紙上部に出力する文字列を設定します。`\usepackage{settings}` の後、`\makecover` より前に一度指定してください。卒論・修論の種別もここで決まります。

```latex
\thesis{２０２５年度卒業論文}
% \thesis{２０２５年度修士論文}
```

:::caution
テンプレートは値を検証・変換しません。提出要件に従い、年度を全角数字で記述してください。
:::
