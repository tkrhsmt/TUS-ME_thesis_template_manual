全角括弧付きで著者年引用を出力するためのコマンド

## 構文

```latex
\citep{Matsukawa:PoF2022}
```
<Card>
![](/TUS-ME_thesis_template_manual/api/images/citep-latex.png)
</Card>

## パラメータ

```latex
\citep{
    key
}
```

- **key**

    BibTeX のエントリのキーを指定します

## 説明

`natbib` の `\citep` をテンプレートが再定義したものです．
`\citealp` の出力を全角丸括弧 `（` `）` で囲みます．
本文の和文引用に使用します．

```latex
先行研究で提案されている\citep{smith2024}。
```

英文キャプションなど、半角括弧を使う箇所には [`\citepe`](../citepe/) を使います。
