## 提供コマンド

`\Gr`、`\Ma`、`\Nu`、`\Pe`、`\Pr`、`\Re`、`\Ra`、`\Sc`、`\St`、`\Ta`、`\Wi` は，それぞれ対応する無次元数をイタリック体で出力します．
`\Pr` と `\Re` は既存定義をテンプレート用に再定義しています．
`\rms` はローマン体で出力します．

| 入力 | 出力 |
| --- | --- |
| `\Gr` | $\mathit{Gr}$ |
| `\Ma` | $\mathit{Ma}$ |
| `\Nu` | $\mathit{Nu}$ |
| `\Pe` | $\mathit{Pe}$ |
| `\Pr` | $\mathit{Pr}$ |
| `\Re` | $\mathit{Re}$ |
| `\Ra` | $\mathit{Ra}$ |
| `\Sc` | $\mathit{Sc}$ |
| `\St` | $\mathit{St}$ |
| `\Ta` | $\mathit{Ta}$ |
| `\Wi` | $\mathit{Wi}$ |
| `\rms` | $\mathrm{rms}$ |

## 倍角ダッシュ

`\――` は，日本語の倍角ダッシュ間の空きを詰めて出力する表記コマンドです．
要旨用スタイルを含む全スタイルで使用できます．
