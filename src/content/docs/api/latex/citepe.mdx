半角括弧付きで著者年引用を出力するためのコマンド

## 構文

```latex
\citepe{Matsukawa:PoF2022}
```
<Card>
![](/TUS-ME_thesis_template_manual/api/images/citepe-latex.png)
</Card>

## パラメータ

```latex
\citepe{
    key
}
```

- **key**

    BibTeX のエントリのキーを指定します

## 説明

テンプレート独自の英文用引用コマンドです．
`\citealp` の出力を半角丸括弧 `(` `)` で囲みます．
図表キャプションなど、和文本文以外での引用に適しています．

```latex
\caption{Comparison with the experiment \citepe{smith2024}.}
```
