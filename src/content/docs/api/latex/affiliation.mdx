表紙の所属を設定するためのコマンド

## 構文

```latex
\affiliation{所属名}
```

## パラメータ

```latex
\affiliation{
    body
}
```

- **body**

    所属名を指定します

## 説明

表紙の提出年月の下に所属を出力します．
卒論では学部・学科名，修論では大学院・研究科・専攻名を設定します．

- 卒業論文の場合

    ```latex
    \affiliation{東京理科大学創域理工学部機械航空宇宙工学科}
    ```

- 修士論文の場合

    ```latex
    \affiliation{東京理科大学大学院創域理工学研究科機械航空宇宙工学専攻}
    ```
