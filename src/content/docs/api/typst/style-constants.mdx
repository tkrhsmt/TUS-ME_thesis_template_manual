`mincho`，`gothic`，`mathf`，`codef` は本文用フォント列，要旨スタイルだけの `english_title` は英文題目用フォント列です．
通常は初期化関数に任せ，直接変更しません．

```typst
#text(font: mincho)[明朝体 mincho]

#text(font: gothic)[ゴシック体 gothic]

#text(font: mathf)[数式体 mathf]

#text(font: codef)[等幅体 codef]
```

`font` は `#text()` のパラメータで，`mincho`，`gothic`，`mathf`，`codef` のいずれかを指定します．
`codef`は等幅体で，コードや数式の表示に使うため，日本語の本文には使えません．
このため，等幅体では豆腐文字が表示されます．
