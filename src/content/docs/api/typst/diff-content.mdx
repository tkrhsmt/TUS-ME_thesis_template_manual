2つの content を差分表示するための関数

## 構文

```typst
#diff-content(a, b, format-plus: ..., format-minus: ...)
```

古い content `a` と新しい content `b` のテキストを比較し，新しい content の書式をできるだけ維持して差分を出力します．
追加・削除の既定の見た目は `diff-string` と同じです．
差分が多い場合には，正常に表示されないことがあります．

:::note[補足]
テンプレート上で直接この関数を使うことはできません．
使用する際には，[`palimset`パッケージ](https://typst.app/universe/package/palimset/)をインポートする必要があります．
:::
