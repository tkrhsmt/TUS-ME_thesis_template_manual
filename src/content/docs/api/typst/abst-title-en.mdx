卒論要旨の英文題目欄を出力するための関数

## 構文

```typst
#abst_title_en(
  title: [The reason to write an abstract in English],
  laboratory: [Tsukahara],
  authors: (
    ( student-id: "75*****",
      name: "Kouji KIKAI"
    ),
    ( student-id: "75*****",
      name: "Rika NODA"
    ),
  )
)
```

## パラメータ

```typst
#abst_title_en(
  title: content,
  laboratory: content,
  authors: array
)
```

- **title**

    卒論要旨の英文題目を指定します

- **laboratory**

    研究室名を指定します

- **authors**

    著者欄を指定します．
    配列の要素は以下のように指定します．

    ```typst
    ( student-id: "学籍番号",
      name: "氏名"
    )
    ```

## 説明

卒論要旨スタイルだけの関数です．
改ページして，英文題目，`[研究室名 Group]`，学生番号と英字氏名を出力します．
修論要旨にはありません．
