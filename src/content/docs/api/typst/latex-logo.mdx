LaTeX ロゴを出力するための content 値

## 構文

```typst
#LaTeX
```

## 説明

テンプレート独自の組版で LaTeX ロゴを出力する content 値です．
括弧は不要です．
LaTeXにおける`\LaTeX` コマンドと同等の出力が得られます．
