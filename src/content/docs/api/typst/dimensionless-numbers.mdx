## 使用方法

数式モードで組版済みの content 値です．
`#Re` のように呼び出します．

```typst
レイノルズ数は #Re，ヌセルト数は #Nu とする．
```
<Card>
![](/TUS-ME_thesis_template_manual/api/images/dimensionless-numbers-typst1.png)
</Card>

或いは，数式モード中では自然に組版されます．

```typst
$
    Re = (rho v L)/mu, quad Nu = (h L)/k
$
```
<Card>
![](/TUS-ME_thesis_template_manual/api/images/dimensionless-numbers-typst2.png)
</Card>
