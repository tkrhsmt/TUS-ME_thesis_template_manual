## 使用方法

数式モードで組版済みの content 値です。`#Re` のように呼び出します。

```typst
レイノルズ数は #Re、ヌセルト数は #Nu とする。
```

## 全定数

`Ar`, `As`, `Be`, `Bm`, `Bi`, `Bo`, `Br`, `Ca`, `Da`, `Cf`, `Cl`, `Cd`, `Cp`, `De`, `Ec`, `Ek`, `Er`, `Eu`, `Fr`, `Ga`, `Gz`, `Gr`, `Ha`, `Hg`, `Ir`, `Ka`, `Kn`, `Ku`, `La`, `Le`, `Ma`, `Mg`, `Mo`, `Nu`, `Oh`, `Pe`, `Pr`, `Ra`, `Re`, `Ri`, `Ro`, `Sc`, `Sh`, `St`, `Stk`, `Ta`, `Wea`, `We`, `Wi`。
