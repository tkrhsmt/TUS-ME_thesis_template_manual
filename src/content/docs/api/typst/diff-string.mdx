2つの文字列を差分表示するための関数

## 構文

```typst
#diff-string(a, b, format-plus: x => text(x, fill: blue, weight: "bold"), format-minus: x => strike(text(x, fill: red, size: 0.75em)))
```

`a` と `b` の文字列を比較し，追加部分を `format-plus`，削除部分を `format-minus` で組版します．
既定では追加を青太字，削除を赤の取り消し線にします．
差分が多い場合には，正常に表示されないことがあります．

:::note[補足]
テンプレート上で直接この関数を使うことはできません．
使用する際には，[`palimset`パッケージ](https://typst.app/universe/package/palimset/)をインポートする必要があります．
:::
