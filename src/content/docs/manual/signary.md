記号は英字・ギリシャ文字のアルファベット順に並べ、上付き添え字、下付き添え字、略語を分けて記載します。

## Alphabet

| 記号 | 意味 |
|---|---|
| `d` | Channel width [m] |
| `L_j` | Computational domain size in `j`-direction [m] |
| `N_j` | Number of grid points in `j`-direction |
| `Re` | Reynolds number, `= ud/ν` |
| `u` | Velocity [m/s] |

## Greek

| 記号 | 意味 |
|---|---|
| `δ` | Channel half width [m] |
| `ε_ijk` | Levi-Civita symbol |
| `ν` | Kinematic viscosity [m²/s] |

## Superscripts

| 記号 | 意味 |
|---|---|
| `( )*` | Normalized by outer variables, e.g., `δ` |
| `( )+` | Normalized by inner variables, e.g., `ν/u_τ` (wall unit) |
| `( )′` | Fluctuation component |
| `overline(( ))` | Statistically averaged |

## Subscripts

| 記号 | 意味 |
|---|---|
| `( )_rms` | Root mean square |
| `( )_w` | Wall |
| `( )_τ` | Wall unit |

## Abbreviations

| 略語 | 意味 |
|---|---|
| CFD | Computational fluid dynamics |
| DNS | Direct numerical simulation |
| LES | Large eddy simulation |
