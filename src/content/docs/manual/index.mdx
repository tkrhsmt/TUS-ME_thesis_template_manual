このWebページは，東京理科大学創域理工学部機械航空宇宙工学科の卒業論文，および大学院創域理工学研究科機械航空宇宙工学専攻の修士論文向け「非公式」LaTeX・Typstテンプレートマニュアルです．

> **まず読むページ**
> 初めて使う人は，[はじめに](./introduction/) → [環境構築・操作方法](./howtouse/) → [LaTeX・Typstの基本](./basic/) の順に進んでください．
> 図表・表記・参考文献は執筆中に随時参照できます．

## 目的から探す

| 目的 | 読むページ |
|---|---|
| テンプレートの対象と構成を知る | [はじめに](./introduction/) |
| 表紙情報と本文ファイルを設定する | [表紙と本文ファイルの設定](./cover/) |
| 組版システムを導入してPDFを作る | [環境構築・操作方法](./howtouse/) |
| 文章・数式・単位を書く | [LaTeX・Typstの基本](./basic/) |
| 図，サブ図，表を配置する | [図表の配置](./figure_table/) |
| 書体，ダッシュ，引用符を使い分ける | [表記に関するあれこれ](./notation/) |
| 文献リストを作り，本文から引用する | [BibTeXによる参考文献一覧の出力](./bibtex/) |
| 修正差分を添削者へ示す | [添削してもらうときの注意点](./check/) |
| 謝辞を書く | [謝辞](./acknowledgement/) |
