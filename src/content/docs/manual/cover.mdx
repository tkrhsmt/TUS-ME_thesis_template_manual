原版の表紙例は「20＊＊年度卒業論文」「【非公式】機械航空宇宙工学科 学位論文テンプレート - LaTeXで論文を書く際に必要な最低限の情報 -」「20＊＊年2月」「東京理科大学創域理工学部機械航空宇宙工学科」「○○研究室」「75＊＊＊＊＊ 姓姓　名名」です。実際の提出時は、以下の `main.tex` の設定を自分の情報へ置き換えます。

:::danger[題目は一字ずつ確認]
学位論文題目は、一文字でも誤ると受理されません。提出要件に記載された題目と完全に一致させてください。長い題目を改行する場合は `\\` を入れます。
:::

## 卒業論文の表紙

```latex
% 卒業「年度」
\thesis{２０＊＊年度卒業論文}

% 論文題目
\title{学位論文の題目}

% 卒業「年」
\date{２０＊＊年２月}

% 大学名・学部名・学科名の間にスペースは入れない
\affiliation{東京理科大学創域理工学部機械航空宇宙工学科}

\laboratory{〇〇研究室}

\author{%
７５＊＊＊＊＊       % 学籍番号は全角7桁
\hskip2\zw          % 学籍番号と氏名の間。削除しない
姓姓　名名           % 姓と名の間は全角1文字
}

\makecover
```

## 修士論文へ変更する箇所

```latex
\thesis{２０＊＊年度修士論文}
\affiliation{東京理科大学大学院創域理工学研究科機械航空宇宙工学専攻}
```

大学名・研究科名・専攻名の間にスペースは入れません。`\date{}` は修了する年を入力します。

## 本文の構成

表紙の後に目次と記号表を出力し、本文のページ番号をアラビア数字で開始します。ページスタイル・カウンター・番号形式を設定する3行は削除しないでください。

```latex
\tableofcontents
\input{chapter/signary.tex}

\clearpage
\pagestyle{normal}
\setcounter{page}{0}
\pagenumbering{arabic}
```

長い論文を一つの `tex` ファイルへ書かず、章ごとに分割して `\input{chapter/xxx.tex}` または `\include{chapter/xxx.tex}` で読み込みます。パッケージ、独自設定、マクロは `\begin{document}` より前のプリアンブル、または `settings.sty` に記載します。

添削時はプリアンブルの `\linenumbers` を有効にすると行番号を表示できますが、提出時は必ずコメントアウトします。画像を省略してタイプセットを速くする `draft` オプションも、添削・提出時には無効にしてください。
