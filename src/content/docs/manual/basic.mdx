## 文章の書き方

### 章・節・小節

この学位論文テンプレートでは，章（chapter），節（section），小節（subsection）に分けて文章を書きます．
記法は，LaTeXとTypstで異なります．

import { Tabs, TabItem, Card } from '@astrojs/starlight/components';

<Tabs>
<TabItem label="LaTeX">

それぞれの章や節のタイトルをつけるには`\chapter{}`，`\section{}`，`\subsection{}`のコマンドを使います．
`{}` の中にタイトルの文字列を入れてタイプセットすると章題目などが出力されます．
<span style="color: red">ある章の中に節が一つだけという状況は避けましょう（ある節の中に小節が一つだけという状況も同様です）．</span>
節（小節）を設けるなら必ず複数設けて内容を分けましょう．
分けるつもりがないのであれば節（小節）を作らないようにしましょう．
また，`\chapter{}` や `\section{}` の次の行には `\label{}` コマンドを使ってラベルを作成します．
これは LaTeX の相互参照の機能を使うために各章・節にラベルをつけているのです．
詳細は[相互参照](#相互参照)を参照してください．

```latex
\chapter{序論}
\label{ch:introduction}

\section{先行研究}
\label{sec:background}

\subsection{A の先行研究}
\label{ssec:previous_A}
```

それぞれの章や節のタイトルをつけるには，`=`，`==`，`===` の記号を使います．
`=` の数が多いほど階層が深くなります．
<span style="color: red">ある章の中に節が一つだけという状況は避けましょう（ある節の中に小節が一つだけという状況も同様です）．</span>
節（小節）を設けるなら必ず複数設けて内容を分けましょう．
分けるつもりがないのであれば節（小節）を作らないようにしましょう．
また，`=`を用いた章・節のタイトルの直後には `< ... >` を使ってラベルを作成します．
これは Typst の相互参照の機能を使うために各章・節にラベルをつけているのです．
詳細は[相互参照](#相互参照)を参照してください．


```typst
= 序論
<ch:introduction>

== 先行研究
<sec:background>

=== A の先行研究
<ssec:previous_A>
```

### 改行・改段落・空白

Microsoft Wordなどでの文書作成に慣れた人はLaTeX・Typstの改行や空白の扱いになかなか慣れないと思います．
まず改行について説明します．
`.tex`や`.typ`ファイル中で改行しても`pdf`ファイルには反映されません．
したがって，文の途中で改行しても全く問題ありません．
次ページの枠内にある例では，【入力】で平家物語の冒頭が 1 文目から 4 文目までは 1 文ごとに改行されています．
しかし，【出力】では改行されずに前の文に続いて表示されています．
次に【入力】の 4 文目と 5 文目に注目しましょう．
間に空行が入っていますね．
この場合は【出力】で改段落しています．
LaTeX・Typstの命令では空行が改段落を意味します．
LaTeX・Typstでは他にも改行の役割を担うコマンドが存在しますが，少しずつ違いがあります．
例えば `\\` （Typstでは`\`）コマンドは「段落内の強制改行」なので改行後に冒頭一文字空きはありません．
文章中で段落を変える際に `\\` で変えようとしている人をときどき見かけますが，これは適切な操作ではありません．
また，`\par`（Typstでは`#par`）コマンドで改段落している人もときどき見ますが，空白行を入れれば改段落できるので `\par` コマンドを使うのは余計な手間ですよね．
逆に，改段落するつもりではない場所で空白行を入れてしまい，うっかり改段落してしまうというケースも見ます．
LaTeX・Typst初心者が引っ掛かりやすいポイントなので気をつけましょう．

### 相互参照

LaTeXやTypstで文書を書くメリットの一つに相互参照の機能が充実していることが挙げられます．
相互参照は「第 1.1.3 節を参照されたい．」や「式 該当式 を代入すると～」のような文脈において，対応する章・節・式・図・表などの番号を文書中から探し出す機能です．
また，ハイパーリンクを有効にしておくことで，`pdf` ファイルに適切なリンクが埋め込まれ，クリックで該当箇所に飛ぶことができ大変便利です．
この学位論文テンプレートでもハイパーリンクを有効化しており，対象の文字列をクリックすると参照先に飛べます．
図表や章題目などを `\label{}`コマンド（Typstでは`<>`）でラベリングし，参照する文章中で `\ref{}`コマンド（Typstでは`@`）を使って呼び出すのが基本的な相互参照の形です．
また，数式を参照する際は `\eqref{}` コマンドの使用が一般的です（Typstではこの区分けはなく，自動的に判別されます）．
図表や式をラベリングしておくことで，式番号や図番号が変わったとしてもその変化に合わせて `pdf` ファイルの出力も変えられます．
また，論文を書き進める途中で章や節の順番が丸ごと入れ替わるといった事態が起きても，相互参照の機能を使っていれば全く問題ありません．
ただし，同じ名前のラベルは使用できないため，名前の重複には気をつけましょう．
存在しないラベル名を参照してもエラーとなり，`pdf` ファイル中での出力は ?? となります（Typstでは重複ラベルを参照時にエラーとなります）．

## LaTeX での数式の書き方

### 基本的な数式の記法

<Tabs>
<TabItem label="LaTeX">

最も基本的な別行立ての数式は `equation` 環境で記述します．
```latex
\begin{equation}
    \frac{\partial u_r}{\partial t} + (\mathbf{u}\cdot\nabla)u_r - \frac{u_\theta^2}{r} = -\frac{1}{\rho}\frac{\partial p}{\partial r} + \nu\left(\nabla^2 u_r - \frac{u_r}{r^2} - \frac{2}{r^2}\frac{\partial u_\theta}{\partial \theta}\right)
    \label{eq:NSr}
\end{equation}
```
<Card>
![](/TUS-ME_thesis_template_manual/manual/images/basic-example-latex5.png)
</Card>

上記の数式はLaTeXでサポートされている最も標準的なコマンドで記述しています．
上付き添え字はキャレット `^`，下付き添え字はアンダースコア `_` で表現します．
したがって，$u_\theta^2$ は `u_\theta^2` と書きます．
ここで注意点として，添え字が $u_\theta^2$ のように一文字であれば問題無いのですが，$R_{ij}$ のように二文字以上の場合は `R_{ij}` のように括弧 `{}` で囲んでください．
分数は `\frac{分子}{分母}` で書き，常微分・偏微分の場合も同様です．
下記のように $\rho$ や $\theta$ のといったギリシャ文字も出力できるほか，$\nabla$ や $\sin$，$\log$ のような数学で使う関数の類もコマンドが存在しています（例：`\nabla`, `\sin`, `\log`）．
$\sin$ や $\log$ は通常アップライト体（立体，Roman 体）で書きます．
$sin x$ などと書くことのないように気をつけましょう．
また，数式中で LaTeX コマンドを使わずに変換で出した全角のθを入れている人をときどき見かけるので気をつけましょう．
上記の式の左辺と右辺で丸括弧の大きさが異なることにも注目してください．
左辺は特に何もしていませんが，右辺は分数がある分，縦方向に括弧の長さが必要です．
括弧の大きさを自動で調整するコマンドとして，`\left(`，`\right)` コマンドがあります．
左辺第二項では速度 $\mathbf{u}$ がベクトルであるため，**Bold** 体になっています．
これは `\mathbf{u}` とすることで出力できます．
このテンプレートでは `unicode-math` を使用しているので `\symbf{u}` というコマンドもサポートされています．
ベクトルをボールドイタリック体 $\symbfit{u}$ にしたい場合は `$\symbfit{u}$` というコマンドを使用してください．
このテンプレートでは `bm` パッケージを使用していません．

上記の式は別行立ての数式でしたが，$E = mc^2$ のように文章中に組み込む数式（インライン数式）を出力する場合は `$E = mc^2$` のように数式を囲って書きます．

複数の数式を並べる場合は `align` 環境を使いましょう．

```latex
\begin{align}
    a^2 &= b^2 + c^2 - 2bc\cos A \label{eq:cosA} \\
    b^2 &= c^2 + a^2 - 2ca\cos B \label{eq:cosB} \\
    c^2 &= a^2 + b^2 - 2ab\cos C \label{eq:cosC}
\end{align}
```

![](/TUS-ME_thesis_template_manual/manual/images/basic-example-latex6.png)
</Card>

`align` 環境では `&` の位置で揃えるように制御しています．
上記の例では $=$ の前に `&` を置いているので，3 式の位置は $=$ の直前で揃っていることになります．
`align` 環境を使えば

```latex
\begin{align}
    \sin 2\alpha &= \sin(\alpha + \alpha) \notag \\
    &= \sin\alpha\cos\alpha + \cos\alpha\sin\alpha \notag \\
    &= 2\sin\alpha\cos\alpha
    \label{eq:double-sin}
\end{align}
```
<Card>
![](/TUS-ME_thesis_template_manual/manual/images/basic-example-latex7.png)
</Card>

のように途中式も入れられます．
式番号を振らなくていい行は `\notag` コマンドを使用します．

```latex
\begin{align}
    \varepsilon\left.\ab(\pdv[order=2]{\tilde{\phi}_1}{t} + g\pdv{\tilde{\phi}_1}{z})\right|_{z=0} &+ \varepsilon^2\left[\pdv[order=2]{\tilde{\phi}_2}{t} + g\pdv{\tilde{\phi}_2}{z} + \tilde{\eta}_1\pdv{}{z}\ab(\pdv[order=2]{\tilde{\phi}_1}{t} + g\pdv{\tilde{\phi}_1}{z})\right. \notag \\
    &\left.\left.+ \pdv{}{t}\ab\{\ab(\pdv{\tilde{\phi}_1}{x}) + \ab(\pdv{\tilde{\phi}_1}{z})^2\}\right]\right|_{z=0} = 0
    \label{eq:multiple-lines}
\end{align}
```
<Card>
![](/TUS-ME_thesis_template_manual/manual/images/basic-example-latex8.png)
</Card>

上記の例は，式の途中で改行を挟む場合の処理方法を示しています．
ただしソースコードは一部，次節で紹介する `physics2` パッケージを使用しているので注意してください．
注目すべき箇所は大括弧 $[\quad]$ の途中で改行を挟んでいる点，代入記法として $|_{z=0}$ を使用している点の二箇所です．
一つの行内で `\left` コマンドに対応する `\right` コマンドが無いとエラーとなります．
大括弧 $[\quad]$ 内で改行する際は一行目で `\left[` に対して `\right.` を使用し，二行目で `\right]` に対して `\left.` を使用することで対処しています．
`\left.` と `\right.` は何も出力されません．
`\left` または `\right` に対応するものを用意するために使用します．
同様に，代入記法としての $|_{z=0}$ は `\right|_{z=0}` に対して `\left.` を使用しています．

場合分けのある数式は `cases` 環境が便利です．
以下の例は Kronecker のデルタです．

```latex
\begin{equation}
    \delta_{ij} =
    \begin{cases}
        1, & i = j \\
        0, & i \neq j
    \end{cases}
    \label{eq:Kronecker}
\end{equation}
```

```typst

```

上記の数式はTypstでサポートされている最も標準的なコマンドで記述しています．
上付き添え字はキャレット `^`，下付き添え字はアンダースコア `_` で表現します．
従って，$u_theta^2$ は `u_theta^2` と書きます．
ここで注意点として，添え字が $u_theta^2$ のように一文字であれば問題無いのですが，$R_{ij}$ のように二文字以上の場合は `R_(i j)` のように括弧 `()` で囲んでください．
また各文字の間には半角空白を入れる必要があります．
Typstの数式環境では，2文字以上の文字列は1つの関数として認識されるためです．
分数は `(分子)/(分母)` で書き，常微分・偏微分の場合も同様です．
Typstでは $\rho$ や $\theta$ のといったギリシャ文字も出力できるほか，$\nabla$ や $\sin$，$\log$ のような数学で使う関数の類もコマンドが存在しています（例：`nabla`, `sin`, `log`）．
使える記号については，[公式のTypstドキュメント](https://typst.app/docs/reference/symbols/sym/)が参考になります．
$\sin$ や $\log$ は通常アップライト体（立体，Roman 体）で書きます．
$sin x$ などと書くことのないように気をつけましょう．
また，数式中で Typst コマンドを使わずに変換で出した全角のθを入れている人をときどき見かけるので気をつけましょう．
左辺第二項では速度 $\mathbf{u}$ がベクトルであるため，**Bold** 体になっています．
これは `bold(u)` とすることで出力できます．
このテンプレートでは`physica`パッケージを使用しているのでベクトル表記には`vb(u)` というコマンドもサポートされています．

上記の式は別行立ての数式でしたが，$E = mc^2$ のように文章中に組み込む数式（インライン数式）を出力する場合は `$E = mc^2$` のように数式前後の`$`に半角スペースを入れないようにして書きます．

複数の数式を並べる場合も，同様に `$` で囲って記述します．

```typst
$
    a^2 &= b^2 + c^2 - 2 b c cos A #<eq:cosA>\
    b^2 &= c^2 + a^2 - 2 c a cos B #<eq:cosB>\
    c^2 &= a^2 + b^2 - 2 a b cos C #<eq:cosC>
$
```

このとき，`&` の位置で揃えるように制御しています．
上記の例では $=$ の前に `&` を置いているので，3 式の位置は $=$ の直前で揃っていることになります．
これを使えば，

```typst
$
    sin 2 alpha &= sin(alpha + alpha) #nonumber\
    &= sin alpha cos alpha + cos alpha sin alpha #nonumber\
    &= 2 sin alpha cos alpha #<eq:double-sin>
$
```

のように途中式も入れられます．
式番号を振らなくていい行は `#nonumber` コマンドを使用します．

```typst
$
  lr(epsilon (pdv(tilde(phi.alt)_1, t, 2) + g pdv(tilde(phi.alt)_1, z)) |)_(z=0)
  &+ epsilon^2 lr(\[ pdv(tilde(phi.alt)_2, t, 2) + g pdv(tilde(phi.alt)_2, z) + tilde(eta)_1 pdv(, z)(pdv(tilde(phi.alt)_1, t, 2) + g pdv(tilde(phi.alt)_1, z))) nonumber\
  &+ lr(pdv(,t){(pdv(tilde(phi.alt)_1, x)) + (pdv(tilde(phi.alt)_1, z))^2}mid(])|)_(z=0) = 0
$
```
<Card>
![](/TUS-ME_thesis_template_manual/manual/images/basic-example-typst7.png)
</Card>

上記の例は，式の途中で改行を挟む場合の処理方法を示しています．
ただしソースコードは一部，次節で紹介する `physica` パッケージを使用しているので注意してください．
注目すべき箇所は大括弧 $[\quad]$ の途中で改行を挟んでいる点，代入記法として $|_{z=0}$ を使用している点の二箇所です．
一つ目の行内で`lr`関数を使用していますが，これは括弧の開きと閉じの対応がない`|`の大きさを自動調整するためです．
`lr`内では，そこに含まれる数式の大きさに応じて括弧の大きさが自動調整してくれます．
2項目では，大括弧$[\quad]$の途中で改行しています．
このときには，一行目で`lr`を使って`[`に対して自動調整を行い，二行目でも`lr`を使って`]`に対して自動調整を行います．
注意点として，`lr`関数は開き側の括弧`[`が呼ばれると`[`に対応する`]`を探してしまうため，これを単なる記号として扱うために`\[`を使用します．
また二行目では`mid`関数を使って`]`だけでなく`|`の大きさも自動調整しています．
`mid`関数は`lr`関数内の括弧と括弧の間にある記号の大きさを自動調整するために使用します．
上記の例では，`]`を括弧の間の記号として扱い，`|`を閉じ側の括弧として扱うことで，双方の大きさを自動調整しています．

場合分けのある数式は `cases` 環境が便利です．
以下の例は Kronecker のデルタです．
```typst
$
    delta_(i j) =
    cases(
        1\, quad & i = j,
        0\, quad & i != j
    )
$
```

### `physics2`・`physica`パッケージ

上記では，基本的なコマンドを紹介するためにわざと面倒な書き方をしました．
しかし，複雑な数式は書くのも大変ですしミスの元になります．
また，数式のコードが長くなるとエラーの原因を探すのも難しくなります．
できるだけ数式を簡単に書くためのツールとして `physics`パッケージ（Typstでは`physica`パッケージ）が開発され，現在まで広く使われています．
ただLaTeXでは，`physics`パッケージでいくつかの問題点を抱えており，最近は`physics`パッケージの代替となる`physics2`パッケージが開発されています．
`physics2`パッケージは現在も開発途上のパッケージであるため，使い方は公式ドキュメントをよく読んでください．
`physics2`パッケージでは常微分・偏微分用のコマンドはサポートされていないので，このテンプレートでは`fixdif`パッケージと`derivative`パッケージを併せて使用しています．
Typstでは`physica`パッケージが今もなお開発が続けられており，常微分・偏微分用のコマンドもサポートされています．

### `siunitx`・`unify`パッケージ

数式中の物理量は *Italic* 体で表記しますが，単位は直立体で表記するのが一般的です．
また，数値と単位の間には空白を設けるのが一般的な書き方です[^1]．
これらの要求を満たして簡単に単位を書けるのが `siunitx`パッケージ（Typstでは`unify`パッケージ）です．

<Tabs>
<TabItem label="LaTeX">

`siunitx`パッケージでは大きく分けてテキストモードとマクロモードの二種類の書き方があります．
テキストモードでは `\si{W/m^2 K}` の数式のように書けるのに対し，マクロモードでは `\si{\watt/\meter^2\kelvin}` のようにそれぞれの単位で用意されているコマンドで出力します．
出力結果はどちらも $\mathrm{W}/\mathrm{m}^2 \mathrm{K}$ です．
${}^{\circ}\mathrm{C}$ のようにマクロモードでしか使用できない単位もあります．
`siunitx` パッケージは非常に便利なので以下のコマンドを積極的に使用しましょう．
単位のみの出力は `\si{}` コマンド，数値と単位を併せての出力は `\SI{}`コマンドを使用します．
`\SI{}`コマンドを使用すると，数値と単位の間に適切な長さの空白を自動で入れてくれます．

|  |  |  |
|:---|:---|:---|
| 【テキストモードとマクロモードと混在】 |  |  |
| **コマンド** | **出力** |  |
| `\si{W/m^2 K}` | $\mathrm{W}/\mathrm{m}^2 \mathrm{K}$ |  |
| `\si[per-mode=symbol]{\watt\per{\square\meter\kelvin}}` | $\mathrm{W}/\mathrm{m}^2 \mathrm{K}$ |  |
| `\si{\watt/\meter^2\kelvin}` | $\mathrm{W}/\mathrm{m}^2 \mathrm{K}$ |  |

|                           |                             |
|:--------------------------|:----------------------------|
| 【さまざまな単位の出力】      |                                           |
| **コマンド**               | **出力**                                   |
| `\SI{45}{W/m^2 K}`        | $45\ \mathrm{W}/\mathrm{m}^2 \mathrm{K}$  |
| `\SI{45}{\degreeCelsius}` | $45\ {}^{\circ}\mathrm{C}$                |
| `\SI{45}{\micro\meter}`   | $45\ \mathrm{\mu m}$                      |
| `\SI{45}{\um}`            | $45\ \mathrm{\mu m}$                      |
| `\SI{45}{mL}`             | $45\ \mathrm{mL}$                         |

最後に示したミリリットル $\mathrm{mL}$ には気をつけてください．
リットル $\mathrm{L}$ を昔は $\ell$ と表記したこともありましたが，「単位は直立体」という原則に合わないのでやめましょう．
また，小文字の $\mathrm{l}$ だと数字の $1$ と紛らわしいので，人名由来の単位ではありませんがリットルは大文字 $\mathrm{L}$ で書くようにしましょう．
