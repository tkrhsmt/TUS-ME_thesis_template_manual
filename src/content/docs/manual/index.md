このWeb版は、東京理科大学創域理工学部機械航空宇宙工学科の卒業論文、および大学院創域理工学研究科機械航空宇宙工学専攻の修士論文向け「非公式」LaTeXテンプレートマニュアルを、内容を省略せず章ごとに再構成したものです。

> **まず読むページ**  
> 初めて使う人は、[はじめに](./introduction/) → [環境構築・操作方法](./howtouse/) → [LaTeXの基本](./basic/) の順に進んでください。図表・表記・参考文献は執筆中に随時参照できます。

## 目的から探す

| 目的 | 読むページ |
|---|---|
| テンプレートの対象と構成を知る | [はじめに](./introduction/) |
| 表紙情報と本文ファイルを設定する | [表紙と本文ファイルの設定](./cover/) |
| TeX Liveを導入してPDFを作る | [環境構築・操作方法](./howtouse/) |
| 文章・数式・単位を書く | [LaTeXの基本](./basic/) |
| 図、サブ図、表を配置する | [図表の配置](./figure_table/) |
| 書体、ダッシュ、引用符を使い分ける | [表記に関するあれこれ](./notation/) |
| 文献リストを作り、本文から引用する | [BibTeXによる参考文献一覧の出力](./bibtex/) |
| 修正差分を添削者へ示す | [添削してもらうときの注意点](./check/) |
| 謝辞や付録を書く | [謝辞](./acknowledgement/)、[付録の記載例](./appendix/) |
| 原版に収録された書誌情報を確認する | [文献一覧](./references/) |

## 原版について

- 対象: 卒業論文・修士論文
- 文書クラス: `jlreq`（`report` 相当、A4、12 pt）
- エンジン: LuaLaTeX
- 参考文献: upBibTeX + `jsme.bst`
- 原版更新履歴: v1.0.0（2023-12-27）、v2.0.0（2024-11-15）、v2.2.0（2026-02-04）
- 作成: Yuki MATSUKAWA / 塚原研究室 学生有志

このテンプレートは学科の論文執筆要件を満たすことを目的に作成されていますが、大学・学科の公式配布物ではありません。利用により生じた問題について、大学・学科・塚原研究室および所属個人は責任を負いません。技術情報も完全な正確性を保証するものではないため、提出要件は必ず最新の案内と照合してください。
